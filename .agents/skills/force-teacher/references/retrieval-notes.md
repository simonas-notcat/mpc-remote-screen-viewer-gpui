# Prior retrieval notes — not device instructions

These are scoped research records, not replacements for the official guide. They
contain no extracted manual text. Check the corpus identity before reusing them;
a changed PDF/version requires reopening the question.

## Default length of newly drawn Grid View notes

**Question:** Before any notes exist, choose a duration once, then add many notes
of that duration by tapping/clicking the grid. This is not editing existing note
ends, changing clip length, or entering Step Sequencer steps.

**Source:** Force User Guide v3.10.1, 468 PDF pages.
SHA-256: `a95b4935e72a1625b26b8c49791554f2eaadfa99baefe5a10b51663a7c8cf127`.

**Search performed:** All 468 extracted-text pages, including whitespace-normalized
cross-line phrase searches; a full 468-page OCR pass (1600-pixel maximum edge,
Tesseract English, no failed pages). The TC, Grid Settings and Draw Mode source
images were also inspected at PDF pp. 96, 153 and 158; the tutorial image at PDF
p. 18 had been inspected earlier. OCR does not imply every diagram was visually
reviewed, and OCR can miss small labels.

**Useful source pointers:**

- PDF pp. 51 and 158: Grid View pencil/draw operations.
- PDF p. 159: changing existing selected notes' start/end positions.
- PDF pp. 95–96: TC types, Time Division and quantization.
- PDF p. 153: Grid Settings and snapping behavior.
- PDF pp. 85–86: sequencer preferences/project defaults; distinguish cropping at
  sequence boundaries from the duration assigned to a newly inserted note.
- PDF pp. 168 and 171: List View step advancement and editing event lengths.
- Other "Note Length" fields concern different operations: arpeggiator (100),
  generated random events (161–162, 336, 341), or auto-sampling (279).

**Result:** No explicit instruction was found establishing a default duration for
newly pencil-drawn notes or connecting that duration to TC. The specific workflow
appears undocumented in the searched guide. This is a search finding, not proof
that the device lacks the feature, that TC cannot affect it, or that another
version of the official manual has the same gap.

Do not present "set TC then draw" as a verified manual procedure based on these
passages. Do not send the user through editing existing notes after they have
clarified that they want to set a default for new notes. Consult only the approved
official manual unless the user explicitly changes that source boundary.

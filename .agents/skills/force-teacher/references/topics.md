# Topic routing hints

These are search aliases, not procedures, model compatibility claims, or a
replacement for the source. Search the chosen corpus and read complete relevant
pages before teaching. Follow its original contents for broader exploration.

| User goal | Source terminology to search |
| --- | --- |
| Slice/chop a loop | Chop Mode; Converting or Assigning Slices |
| Trim or process a sample | Sample Edit Mode; Trim Mode; Processing Slices & Samples |
| Record a sample | Sampler; Sampling (Recording) |
| Enter drum steps | Step Sequencer; Drum Mode; Lanes Mode |
| Set the default duration for new grid notes | Pencil / Draw Mode; Timing Correct / Time Division; read the scoped finding in `references/retrieval-notes.md` before claiming a documented link |
| Change existing note lengths | Grid View; Edit End; List Edit Mode; distinguish this from default entry duration |
| Change clip/sequence length | Main Mode; Sequence Section; Clip Editor |
| Launch clips/scenes | Clip Matrix Mode; Launching Clips; Launch Mode |
| Change track volume/pan/sends | Track Mixer; Pan & Volume; Sends |
| Change individual drum-pad levels | Pad Mixer |
| Edit drum/keygroup parameters | Track Edit Mode; Drum Tracks; Keygroup Tracks |
| Arrange a song | Arrange Mode; Working with the Linear Arranger |
| Route audio or cue tracks | I/O; Audio Device; Cueing Tracks |
| Use knobs/macros | Q-Link Edit; Learning Macro Assignments |
| Save or export | Save Window; Audio Mixdown; Saving Your Work |
| Check physical controls | Hardware Features; Top Panel; Rear Panel |
| Find a plugin's controls | Plugins; the exact plugin name, e.g. DrumSynth |

Do not assume a preset's pad-to-sound mapping. Prior live drum lessons establish
only that session's assignments, not a universal kick/clap/hi-hat map.
